# 보관 범위와 한계

이 저장소는 2026-09-17 이후 샌드박스에 실제로 남아 있던 KJournal 작업 산출물을 기준으로 정리되었습니다. 대화 기록에는 4.8 관련 요청과 분석이 포함되어 있으므로 변경 로그는 4.8부터 작성했지만, 정확한 `KJournal 4.8.apk` 바이너리 자체는 현재 작업 환경에 남아 있지 않아 임의로 만들어 넣지 않았습니다. 보관된 가장 이른 APK는 KJournal 4.9 계열입니다.

`reverse-engineering/kjournal-pb6-decoded/`는 제공된 APK를 apktool로 디코드한 결과입니다. 이는 원래 개발자가 작성한 Kotlin/Java 프로젝트의 원본 소스가 아니라 난독화·최적화된 배포 APK에서 복원한 smali·리소스·자산입니다. 원본 Gradle 프로젝트가 제공되지 않은 부분은 역공학 결과와 빌드 스크립트로 보존했습니다.

서명 개인키, NAS 비밀번호, Codeberg/GitHub 토큰은 보안상 저장하지 않았습니다. 따라서 저장소의 기본 빌드는 unsigned APK를 생성하며, 업데이트 호환성을 위한 실제 서명은 소유자가 별도로 보관한 키를 `KEYSTORE` 환경변수로 주입해야 합니다.
