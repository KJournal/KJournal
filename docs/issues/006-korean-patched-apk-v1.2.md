# 한국어 패치 APK 및 KJournal V1.2 보존

## 요청

사용자에게 실제로 보이는 UI를 가능한 범위에서 한국어로 현지화하고, 약물 데이터베이스 `assets/Substances.json`은 그대로 보존한다. 앱 이름은 `KJournal V1.2`, 개발자 정보는 `지원(정병이) 개발`로 표시하며 Discord와 X 핸들은 유지한다.

## 적용 범위

홈, 하단 탭, 설정, 통계, 저널/약물 기록, 약물 추가·조회, 섭취 경로, 검색, 경고창, 다이얼로그, 데이터 내보내기·가져오기 등 주요 사용자 UI를 대상으로 했다. 리소스 문자열은 `values-ko/strings.xml`을 우선 사용했고, Compose 기반 화면에서 리소스가 아닌 하드코딩 문자열은 관련 smali 파일을 최소 범위로 수정했다.

## 보존된 결과물

최종 후보는 `release/apk/PsyLog_Korean_Patched_v1.apk`와 `release/apk/PsyLog_Korean_Patched_v2.apk`이다. 두 파일의 크기와 SHA-256은 `release/APK_CATALOG.md` 및 세션 기록에 함께 적었다. 기존 APK와 역공학 소스는 삭제하지 않고 그대로 유지했다.

## 검증 메모

이전 작업에서 apktool 재빌드와 uber-apk-signer 서명 흐름을 성공적으로 확인했다. 저장소에는 전체 디코드 소스와 재현용 빌드 스크립트가 남아 있다. 실제 기기에서의 설치·업데이트·모든 입력 경로 검증은 사용자가 보유한 테스트 기기와 서명키로 최종 확인해야 한다. 특히 서명 개인키는 보안상 저장소에 포함하지 않는다.

## 상태

이 문서는 완료된 변경의 추적성을 위한 기록이다. 추가 개선이 필요하면 별도 커밋으로 진행하며 기존 APK, 로그, 문서, 브랜치 이력은 삭제하지 않는다.
